# hippocampus-gen
Test data generator for Hippocampus

This will create sample or test data for use with the [Hippocampus][https://github.com/fastbean-au/hippocampus] service. The data itself is not meant to be particularly meaningful.

With this initial iteration of the generator, a wordlist is used to generate the event names, descriptions and bodies of memories. The wordlist used is the [MIT 10000 word list](https://www.mit.edu/~ecprice/wordlist.10000). The data itself is not meant to be particularly meaningful, and this iteration delivers on that.

Eventually, this perhaps will be expanded to accept books as input, with chapters as events, and paragraphs as memories as an option for more meaningful memories.
